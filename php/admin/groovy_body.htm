The JVM's maximum heap is the memory ceiling for the Groovy server: every query result it builds in memory counts against it. WaSQL does not set it, so Java uses its default. To change it, pass -Xmx in JAVA_OPTS, for example -Xmx2g for 2 GB or -Xmx512m for 512 MB. The groovy launcher passes JAVA_OPTS to Java, so it also applies to any other Groovy command run as the web server user. Leave room for the database, the web server and PHP: on a shared server, stay well under half the RAM.
